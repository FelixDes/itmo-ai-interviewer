# Скриншоты для презентации

Положите сюда три файла с точными именами. Пока их нет, Slidev покажет
битые картинки — на сборку это не влияет.

| Файл | Что снять | Где взять |
|---|---|---|
| `01-report-top.png` | Верх карточки: рекомендация, балл, уверенность, объяснение и таблица обязательных требований со статусами | Кабинет рекрутера → кандидат со статусом «готово» |
| `02-report-answer.png` | Раскрытый разбор одного ответа: видео, расшифровка, шесть критериев, цитата с таймкодом | Там же, раскрыть блок в разделе «Разбор по вопросам» |
| `03-candidate.png` | Экран кандидата: две плитки, вопрос, кнопка «Ответить» по центру | Пройти по ссылке кандидата |

Ширина 1200–1600 px, PNG. Обрезать по содержимому, без панели задач и вкладок
браузера — на слайде они только отвлекают.

На `03-candidate.png` в плитке «Вы» видно изображение с камеры. Снимите так,
чтобы в кадре не было ничего лишнего: это уйдёт в презентацию.
